!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

:Author: Matthew Leingang <leingang@cims.nyu.edu>
:Date:   |date|

This is a week-by-week calendar of topics covered in Calculus III.  As a rule of thumb,
the topics are generally to be spread out equally during the week, so if there are two
topics, each one takes one class period, while if there are three, each should take
two-thirds of a class period.

.. More details, including specific learning objectives and the amount of time to spend on
   each section, can be found in the lesson guide. [NOT YET!]

Notes
-----


.. [#ws] The first week is a good time to do something interactive like a worksheet.  This
   would fill extra time in the case of TR classes

.. [#wk1] Monday classes do not meet this week.  So MW sections will
   only meet Wednesday.  TR sections can do more from Section 10.1.

.. [#s108] Don't worry about the normal and binormal vector fields.  

.. [#s109] 

.. [#wk7] Monday and Tuesday are holidays (Columbus Day) here so each
   section will only meet once.  Some big sections won't have
   recitation either.  Still it's a good week for the midterm.

.. [#dgc] "DGC" stands for `Div, Grad, Curl and all that`, by H.M. Schey, 4th ed., Norton.
   This is a nice monograph on the physical reasons behind the vector calculus theorems.
   We will stick with Stewart for the guiding theme.

.. [#wk13] This is Thanksgiving week.  Wednesday is declared a Monday
   (why it's not declared a Friday I don't understand).  This doesn't
   have too much effect on MW sections, but we should be aware that
   attendance will be light on Wednesday.  TR classes will officially
   only meet once this week.
